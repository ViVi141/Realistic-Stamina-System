RSS v6.2.1 Change Notes
=======================
From 6.2.0 → 6.2.1 (config 6.2.1). Dedicated/listen server load crash fix.
Keep server & clients on the same mod build.

[EN]

• Skip stamina tick until character World/Physics/Anim are ready; retry via CallLater.
• Land speed sampling uses Physics.GetVelocity with position-delta fallback.
• Same safe velocity path on RPC / debug / slope helpers.

• 角色 World/Physics/Anim 未就绪时跳过本 tick，并续约 CallLater。
• 陆地测速改用 Physics.GetVelocity，接近 0 时回退位置差分。
• RPC / Debug / 坡度等热路径同步改为安全测速。
