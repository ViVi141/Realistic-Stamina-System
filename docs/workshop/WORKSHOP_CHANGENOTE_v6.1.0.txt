RSS v6.1.0 Change Notes
=======================
From stable 3.23.1 → 6.1.0 (config 6.1.0). No automatic cross-major migration.
(6.0.0 was published but not widely adopted — treat this as the first broad v6 jump.)
Re-select Elite / Standard / Tactical in Settings, or use tools/optimized_rss_config_*_v6.json.
Keep server & clients on the same mod build.

Current play feel (6.1.0 defaults)
----------------------------------
• Drain-first: prefer burning W′ / STA over clamping Physics velocity.
• SetSpeedLimit still applies phase gears / soft cruise / limp (merged with 1.7+ foliage/wire).
• No default Physics hard-clamp; no continuous CP metabolic speed servo.
• Metabolic accounting uses measured speed (v_meas), not min(v_meas, v_limit).

• NEW: Sprint gate = aerobic threshold + W′ Schmitt latch (not short-burst time CD)
• NEW: Sprint speed = march Sprint gear first; available-power invert is a soft cap; W′ empty → Run-scale fallback

• NEW: W′-linked presentation — maps W′ into engine stamina so native muzzle sway rises when W′ is low; RSS-CPCR drive + manual breath samples (Exhaustion signal); no custom sway script

Known limitations (engine)
--------------------------
• W′ empty vs speed: In a strict CP–W′ model, once W′ is empty you cannot sustain the
  same supra-CP effort — speed should drop. In Reforger, forcing a large speed cut while
  the animation stays in the same gait (esp. Run) desyncs feet vs displacement (sliding).
  To avoid that, 6.1.0 keeps the current movement state where possible and bills the
  excess to STA instead of hard-clamping Physics to a much lower v.
• Walk + scroll speed: Native wheel / Walk key share DynamicSpeed. 6.1.0 no longer
  force-clears DynamicSpeed each tick (that was leftover from old “fake Walk” hacks).
  Releasing Walk still restores pre-Walk speed via vanilla OnEndWalk; SetSpeedLimit
  remains a max cap only.

已知限制（引擎）
--------------
• W′ 耗尽 vs 降速：按严格 CP–W′，W′ 空后无法以相同强度持续高于 CP 的运动，现实应为
  降速。但在 Reforger 中强行大幅压速而动画仍停在同一相位（尤其 Run）会滑步。6.1.0
  在可行范围内保持当前运动状态，超额改消耗 STA，而非物理硬钳到远低于动画带。
• Walk + 滚轮调速：原生滚轮与 Walk 键共用 DynamicSpeed。6.1.0 已去掉每 tick 强清
  DynamicSpeed（旧「假 Walk」残留）。松 Walk 仍由原版 OnEndWalk 恢复按键前速度；
  SetSpeedLimit 只作上限。

Upgrade tip: Custom JSON from 3.x is not a drop-in for 6.x — start from a baked preset.
If you briefly tried 6.0.0: re-select a preset after updating so 6.1.0 defaults apply.
