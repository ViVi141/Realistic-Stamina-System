RSS v6.1.3 Change Notes
=======================
From 6.1.2 → 6.1.3 (config 6.1.3). Removes in-mod CPR stamina re-activate compat.
Keep server & clients on the same mod build.

[EN]
• REMOVED: SCR_RSS_StaminaComponentCompat — no longer re-activates character stamina
  components that third-party prefabs left Enabled 0 (e.g. Conflict PVE Remixed).
• PlayerBase resolves stamina via Cast(GetStaminaComponent()) only.
• Use a separate compatibility mod (or fix prefabs) if pairing RSS with CPR-style packs.

[中文]
• 移除：SCR_RSS_StaminaComponentCompat — 不再对第三方 prefab（如 CPR）Enabled 0
  的体力组件做运行时 Activate。
• PlayerBase 仅 Cast(GetStaminaComponent())。
• 与 CPR 联用请改用独立兼容模组，或修正角色 prefab。
